Le fichier municipalities.json ne conserve que des champs publics : code géographique,
nom, désignation, code postal du siège, région administrative et MRC.
Les noms des élus et les coordonnées personnelles du répertoire source ne sont pas inclus.

Import constitué pour Mijoté le 19 octobre 2026.
Le code postal est celui du siège municipal, pas la liste de toutes les adresses d'une ville.
